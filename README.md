# 🖼️ Image Steganography using Python and Tkinter

A **GUI-based Image Steganography application** built with **Python** and **Tkinter**, allowing users to **hide and extract secret messages inside images** securely.  
This project demonstrates how digital images can be used as carriers for confidential data using simple encoding and decoding techniques.

---

## ✨ Features
- 🔒 Encode (hide) secret text messages inside images  
- 🧩 Decode (extract) hidden messages from images  
- 🖥️ Easy-to-use **Tkinter-based GUI**  
- 🧠 Built using **Python** and **Pillow** for image handling  
- 📁 Supports common formats like `.png`, `.jpg`, `.jpeg`

---

## 🧰 Tech Stack
- **Python**
- **Tkinter** (for GUI)
- **Pillow** (PIL – for image processing)
- **Base64 / Bitwise Encoding** (for data hiding)
